# Retention — DRAFT FOR LAWYER

The lawyer sets the periods. The code keeps everything until a rule is decided; nothing is deleted
automatically today, except as noted.

| Data                                                                                | Where                                                              | Proposed period (lawyer to confirm)                                                                              | What the code does today                                                                               |
| ----------------------------------------------------------------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Medical record: answers, photos, doctor decision and reason, prescription, messages | `clinical.cases`, `answers`, `photos`, `messages`, `prescriptions` | The period Romanian law sets for medical documentation (to confirm: Law 46/2003 and Order 1410/2016 / CMR rules) | Kept; account deletion records a request and does not erase it (`src/clinical/patient/data-rights.ts`) |
| Unsubmitted evaluation (account created, never sent to a doctor)                    | `clinical.cases` with status `draft`                               | Proposal: 90 days after last change                                                                              | Kept — **job to add once the period is decided**                                                       |
| Photos of a declined case                                                           | storage bucket                                                     | Same as the medical record, or shorter if the lawyer allows                                                      | Kept                                                                                                   |
| Consents and withdrawals                                                            | `clinical.consents`                                                | Life of the account + limitation period, as proof                                                                | Kept (append-only)                                                                                     |
| Audit log (who opened which record, never content)                                  | `clinical.audit_log`                                               | Proposal: 5 years                                                                                                | Kept (append-only)                                                                                     |
| Payments, invoices                                                                  | Stripe, invoicing provider, `clinical.payments`, `invoices`        | 10 years (accounting law, Law 82/1991, to confirm)                                                               | Kept                                                                                                   |
| Delivery address                                                                    | `clinical.patients`                                                | Until account closure, then minimal for invoices                                                                 | Cleared on deletion request by the admin (manual today)                                                |
| E-mail outbox                                                                       | `clinical.outbox`                                                  | Proposal: 90 days                                                                                                | Kept — job to add                                                                                      |
| Cookie-consent preference                                                           | cookie `telegen_consent`                                           | 6 months                                                                                                         | Expires after 6 months                                                                                 |
| Server logs                                                                         | Vercel                                                             | Vercel default (to confirm in the Vercel plan)                                                                   | Logs never contain health data (lint rule + scan)                                                      |

Deletion request flow today: the patient asks in /cont → row in `clinical.deletion_requests` → the admin
sees it in /admin → applies the decided rules. Automating it waits for the periods above.
